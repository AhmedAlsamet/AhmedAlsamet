## About Me

I'm a software developer based in Sana'a, Yemen, with more than three years of experience building mobile and web-based systems.

My main stack is **Flutter, Laravel/PHP, and MySQL**. I have worked on live-streaming applications, voice rooms, chat systems, electronic examination platforms, marketplaces, payment systems, notifications, and location-based applications.

I usually work across the full development process, including:

* Building Flutter applications for Android, iOS, Web, and Windows
* Developing REST APIs and admin dashboards
* Designing and maintaining MySQL databases
* Implementing real-time features using WebSockets, Socket.IO, Redis, and Agora
* Integrating Firebase, payment services, maps, notifications, and third-party APIs
* Maintaining and improving applications after release
